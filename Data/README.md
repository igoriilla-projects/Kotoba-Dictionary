# Локальные данные словаря

В Git хранятся этот файл и `manifest.json`: версия схемы, число записей и хэши исходного образа и базы. Содержимое исходного словаря не включено в репозиторий и не распространяется под MIT-лицензией кода Kotoba.

Для сборки используйте собственный исходный образ `YARXI.dmg`:

1. Поместите его в корень проекта под именем `YARXI.dmg`.
2. Из корня проекта выполните:

   ```sh
   python3 tools/extract_database.py YARXI.dmg
   ```

Конвертер без монтирования и запуска исходного приложения создаст:

- `Data/yarxice.db` — неизменную исходную бинарную базу;
- `Data/dictionary.sqlite` — базу SQLite для приложения и виджета;
- `Data/manifest.json` — манифест экспорта.

Образ, обе базы и временные файлы исключены через `.gitignore`. Не добавляйте их принудительно в Git. Исходные файлы сохраняйте для повторного экспорта и проверок. Состав конкретного проверенного образа и контрольные суммы указаны в манифесте; конвертер рассчитан на этот формат источника.

После подготовки данных:

```sh
xcodegen generate
bash tools/build.sh
bash tools/test.sh
```

При переносе уже настроенного проекта можно локально скопировать исходный образ и обе базы. Данные обучения пользователя в этот каталог переносить не нужно: они хранятся отдельно в App Group и не входят в Git.
