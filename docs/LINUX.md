# Kotoba для Linux x64

Версия 1.1.0 работает офлайн и использует X11 или XWayland. Сборки проверяются
на Ubuntu 24.04 x86-64. В комплект входят .NET и японский шрифт. [Linux в документации Avalonia](https://v11.docs.avaloniaui.net/docs/overview/supported-platforms/)

## Установка и запуск

Для Ubuntu и Debian используйте пакет `.deb`. После установки Kotoba появится
в меню приложений, а из терминала запускается командой `kotoba`.

```sh
sudo apt install ./build/linux/kotoba_1.1.0_amd64.deb
kotoba
```

Переносимую сборку можно распаковать в любую доступную папку.

```sh
tar -xzf build/linux/kotoba-1.1.0-linux-x64.tar.gz
./kotoba/kotoba
```

Переносимая сборка использует системные SQLite, X11, Fontconfig, ICU и OpenSSL.
Список пакетов для Ubuntu и Debian содержится в метаданных `.deb`.

## Работа со словарём

- **Ctrl+F** открывает поиск по кандзи, хирагане, ромадзи и русскому тексту.
  В X11 **Ctrl+Alt+J** возвращает Kotoba и выделяет запрос даже из другого
  приложения. В **Настройки → Сочетания клавиш** можно поменять комбинацию,
  отключить её или вернуть исходную.
- В Wayland задайте глобальное сочетание для команды `kotoba --search`
  в настройках рабочего стола. Для переносимой сборки укажите полный путь к
  исполняемому файлу. Команда открывает поиск в уже запущенном Kotoba.
- Нажмите на кандзи в заголовке слова, чтобы открыть его чтения, значение
  и полный список связанных слов. **Обзор** выбирает записи вручную или по таймеру.
- Сохраняйте записи во входящие или именованные списки. В повторении **Пробел**
  показывает перевод, **1–3** ставят оценку, **Ctrl+Z** отменяет последнюю.
- В настройках можно открыть одну настольную карточку, менять её размер,
  источник, чтение, таймер и режим «Поверх остальных окон». Компоновщик
  рабочего стола управляет положением и порядком окон.
- Открытая карточка продолжает работать при закрытии главного окна. Сочетание,
  команда `kotoba --search` и значок Kotoba в поддерживаемом системном трее
  возвращают окно. **Выйти из Kotoba** завершает приложение вместе с карточкой.
- **Настройки → Журнал изменений** открывает журнал, который также входит
  в оба пакета. [Журнал версий Linux](../Linux/CHANGELOG.txt)

Данные обучения и настольной карточки хранятся в `$XDG_DATA_HOME/kotoba`
или `~/.local/share/kotoba`. Настройки лежат в `$XDG_CONFIG_HOME/kotoba`
или `~/.config/kotoba`. Пакет устанавливает словарь в `/opt/kotoba`, а
учебные данные и настройки остаются в домашнем каталоге.

## Сборка и проверка

Понадобятся .NET SDK 10, Python 3 и `dpkg-deb`. Подготовьте локальный образ
YARXI и справочник JMdict. При наличии `Data/yarxi.db` сборка использует
расширенный экспорт с сохранёнными идентификаторами. [Подготовка словаря](../Data/README.md)

```sh
bash tools/build_linux.sh
bash tools/test_linux.sh
```

Проверка требует `xvfb-run`, `xauth` и `libXtst.so.6` (пакет `libxtst6`).
Она проверяет оба пакета, запускает
общие тесты словаря и обучения и проходит основные сценарии Linux-интерфейса
на виртуальном экране X11, включая нажатия по отдельным кандзи и глобальное
сочетание. Снимки проверок находятся в `build/linux/previews`.
